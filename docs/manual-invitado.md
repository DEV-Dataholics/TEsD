# Manual del invitado — Cómo confirmar tu asistencia

Si recibiste un enlace para confirmar tu asistencia a un evento, esta guía es para ti. **No necesitas crear una cuenta** para responder.

## 1. Abrir tu enlace

El enlace que recibiste se ve parecido a:

```
https://tueventosindramas.dataholics.com.mx/#rsvp=xxxxxxxxxxxxxxxxx
```

Ábrelo directamente desde tu teléfono o computadora. Es un enlace **personal y privado**: no lo compartas con otras personas, ya que permite ver y responder por ti.

## 2. Confirmar o declinar

1. Al abrir el enlace, verás el nombre del evento y tu información de invitación.
2. Elige si asistirás o no.
3. Puedes agregar una nota si lo necesitas (por ejemplo, una restricción alimentaria adicional).
4. Pulsa **Enviar respuesta**.

Puedes volver a abrir el mismo enlace más adelante para cambiar tu respuesta, mientras el enlace siga vigente.

## 3. ¿Por qué mi enlace no funciona?

Un enlace puede dejar de funcionar por estas razones:

| Situación | Qué significa |
| --- | --- |
| **Enlace vencido** | Los enlaces vencen 7 días después de la fecha del evento, o en 90 días si el evento no tiene fecha definida. |
| **Enlace revocado** | El organizador canceló esa invitación específica. |
| **Enlace rotado** | El organizador generó un enlace nuevo; el anterior ya no sirve. Pide al organizador que te reenvíe el enlace vigente. |
| **Enlace mal copiado** | Asegúrate de copiar el enlace completo, incluida la parte después de `#rsvp=`. |

En cualquiera de estos casos, contacta directamente al organizador del evento — el sistema no puede generar un enlace nuevo por sí mismo sin que el organizador lo autorice.

## 4. Privacidad

- Tu respuesta solo la ve el organizador del evento (y el administrador del sistema, si necesita dar soporte).
- El enlace no aparece en buscadores ni se comparte con terceros.
- No se te pedirá tu contraseña porque no necesitas una cuenta para responder.
